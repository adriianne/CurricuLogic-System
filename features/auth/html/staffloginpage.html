About CurricuLogic

A prerequisite verification and subject recommendation tool for University of Cebu students. It checks academic records against each programme's prospectus and explains every result, so advising works from a verified list instead of a manual check.

Features

  1. 1

    Prerequisite checking

    Every chain, year standing, and elective rule matched against the record.

  2. 2

    Explained results

    See the exact requirement behind every subject a student can't take yet.

  3. 3

    Load planning

    A suggested set of subjects that fits within allowable units.
