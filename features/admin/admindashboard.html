Bulk account creation

Upload a CSV or Excel file to create multiple accounts at once. Supports students, faculty, registrar, department, and admin accounts.

One account Many at once (file)
File format Required columns: first_name, last_name, email, role. For staff (faculty, registrar, department): employee_id is required. For students: student_id is required. Every role except admin also needs program_code -- which programme decides a student's curriculum, and is what each staff role's per-programme account cap is checked against. Optional: password, department, year_level.
Select account type

Choose a role and a programme and the template is filled in for them. A file you upload is then accepted only for that role and programme: any row that belongs to another one is rejected with the reason. Leave "All roles" and "All programmes" to upload a mixed file.
