Bulk account creation

Upload a CSV or Excel file to create multiple accounts at once. Supports students, faculty, registrar, department, and admin accounts.

One account Many at once (file)
File format
  • Required columns: first_name, last_name, email, role.
  • Staff (faculty, registrar, department): leave employee_id blank, it is assigned automatically (EMP-00001, EMP-00002, ...). Only an admin row needs one (SYS-...) plus a username.
  • Students: student_id is optional. Give it if the student already has one (7 digits), or leave it blank and the system assigns the next number.
  • Programme: every role except admin also needs program_code. It decides a student's curriculum, and is what each staff role's per-programme account cap is checked against.
  • Optional: password, department, year_level.
Select account type

Choose a role and a programme and the template is filled in for them. A file you upload is then accepted only for that role and programme: any row that belongs to another one is rejected with the reason. Leave "All roles" and "All programmes" to upload a mixed file.
